# A Forgotten Lost World

**A Forgotten Lost World** — двумерная sandbox-игра с элементами выживания, исследованием мира, сбором ресурсов, добычей полезных ископаемых и сражениями с боссами.

Проект разрабатывается на **Godot Engine**.

## Возможности

- Двумерный игровой мир
- Элементы выживания
- Исследование мира
- Сбор ресурсов
- Добыча полезных ископаемых
- Сражения с боссами

Игра находится в разработке.

## Начало работы

### Требования

- Godot Engine 4.7 или совместимая версия.

### Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/dizer6143-dot/Game-2d-Sandbox-name-a-forgotten-lost-world-.git
```

Откройте папку проекта через Godot Engine.

Выберите файл `project.godot` и запустите проект через редактор Godot.
